# 움짤공방

동영상·사진·GIF로 움짤을 만드는 개인용 무료 웹앱입니다. 서버 없이 브라우저 안에서만 동작하고, 고른 파일은 어디에도 올라가지 않아요. 워터마크도 없어요.

## 할 수 있는 것

| 구분 | 기능 |
|---|---|
| 가져오기 | 동영상 → 움짤(구간·초당 프레임 선택), 사진 여러 장 → 움짤, GIF 열어서 편집, 한 장씩 찍어서 이어붙이기(스톱모션), 여러 소스 이어붙이기 |
| 프레임 | 프레임 빼기/다시 넣기, 순서 바꾸기, 복제, 삭제 |
| 속도 | 프레임 간격 0.02~2초, 느리게/빠르게, 정방향·역방향·부메랑 |
| 캔버스 | 원본/1:1/4:5/9:16/16:9/3:4/4:3/2:1, 꽉 채우기·전체 보이기, 흐린 배경·단색 배경, 드래그로 위치, 두 손가락으로 확대, 90° 회전, 좌우 반전 |
| 필터 | 프리셋 12종 + 밝기·대비·채도·색온도·비네팅 |
| 텍스트 | 여러 줄 글자, 글꼴 7종, 색, 그림자·외곽선·박스, 크기, 나타나는/사라지는 프레임 지정 |
| 스티커 | 이모지 스티커, 크기·위치·표시 구간 |
| 그리기 | 펜 색·굵기, 되돌리기 |
| 테두리 | 두께·색 |
| 저장 | GIF(크기 4단계, 색상 수, 반복 횟수) 또는 동영상(MP4/WebM, 반복 횟수) |

ImgPlay에 있는 기능 중 Live Photo 읽기, GIF 검색(GIPHY), AI 배경 지우기, 콜라주, 음악 넣기는 빠져 있어요. 웹 브라우저에서 할 수 없거나 외부 유료 API가 필요한 기능이에요.

## 깃허브에 올려서 폰에서 쓰기

1. [github.com](https://github.com)에 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름을 정하고(예: `umjjal`) **Public**을 고른 뒤 **Create repository**
3. 새 저장소 화면에서 **uploading an existing file** 링크 → 이 폴더 안의 파일과 폴더를 **모두** 끌어다 놓기  
   (`index.html`이 저장소 맨 위에 있어야 해요. `lib`, `icons` 폴더도 꼭 같이)
4. **Commit changes**
5. 저장소의 **Settings → Pages** → Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 두고 **Save**
6. 1~2분 뒤 `https://내아이디.github.io/umjjal/` 로 접속

### 홈 화면에 앱처럼 추가

- iPhone: Safari로 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- Android: Chrome으로 열기 → 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**

한 번 열어두면 앱 파일이 저장돼서 인터넷이 끊겨도 열려요. 글꼴은 처음 쓸 때 내려받아요.

### 알아둘 점

- 깃허브 무료 계정은 **공개 저장소**에서만 Pages를 쓸 수 있어요. 공개되는 건 이 앱의 코드뿐이고, 내가 만드는 움짤이나 사진은 폰 안에서만 처리돼요.
- 주소를 아는 사람은 누구나 같은 앱을 쓸 수 있어요(각자 자기 기기에서만 동작).
- ImgPlay와는 관계없는 개인 프로젝트예요. 앱 이름과 로고도 따로 만들었어요.
- 코드를 고친 뒤에는 같은 방법으로 파일을 다시 올리면 돼요. 반영이 늦으면 `sw.js` 맨 위 `umjjal-v1`을 `umjjal-v2`처럼 바꿔서 올리세요.

## 저장이 안 될 때

- iPhone: 결과 화면의 **사진에 저장 · 공유** → **이미지 저장**을 누르면 사진 앱에 움직이는 GIF 그대로 들어가요. 또는 결과 이미지를 길게 눌러 저장.
- 카카오톡 같은 앱 안의 브라우저에서는 저장이 막힐 수 있어요. Safari나 Chrome에서 열어주세요.
